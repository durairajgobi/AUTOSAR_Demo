COMPILATION & INTEGRATION ROADMAP
================================================================================

Step 1: Include Headers
  In your application code:
    #include "Rte_DoorControlSWC.h"
    #include "Com.h"
    #include "Dem.h"
    #include "CanIf.h"

Step 2: Initialize Stack (in main.c)
  CanIf_Init();
  Com_Init();
  Dem_Init();
  Rte_Init_DoorControlSWC();
  
  CanIf_Start();
  Com_Start();
  Dem_Enable();

Step 3: Update Application Code
  Replace direct sensor/CAN access with RTE functions:
    Rte_Read_DoorSensor_In_SensorData(&sensor)
    Rte_Read_DoorCommand_In_DoorCommand(&cmd)
    Rte_Write_DoorStatus_Out_DoorStatus(&status)
    Dem_SetEventStatus(eventId, eventStatus)

Step 4: Call Periodic Functions
  In main loop (every 10-50ms):
    CanIf_MainFunction();
    Com_MainFunction();
    Dem_MainFunction();

Step 5: Compile & Link
  gcc -c Com.c Dem.c CanIf.c Rte_DoorControlSWC.c -o output/
  gcc -c DoorControl.c Hal.c main.c CanDrv.c -o output/
  gcc -o firmware.elf output/*.o
